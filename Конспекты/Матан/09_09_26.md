# Комплексные числа
$C = \{(a, b) | a,b \in R\}$
$z_1 = (a,b); z_2 = (c,d)$
$z_1 + z_2 = (a + c, b + d) , 0 = (0, 0)$
$z_1 \cdot z_2 = (ac - bd, bc+ad), 1 = (a, 0)$
#### Алгебраическая форма
$z = a + ib$
$a = Re; ib = Im$

$i = (0,1)$
$i^2 = (-1, 0)$

$(a+ib)(c+id) = ac + ibc + iad + i^2bd = (ac - bd) + i(bc + ad)$
#### Геометрическая форма
Вектор $(a,b)$
$\cdot i$ - поворот на $90\degree$
#### Тригонометрическая форма
$|z| = \sqrt{a^2 + b^2}$
$z = a + ib = \sqrt{a^2 + b^2} (\frac{a}{\sqrt{a^2 + b^2}} + i\frac{b}{\sqrt{a^2 + b^2}}) = |z| \cdot (\cos{\varphi} + i \cdot \sin{\varphi})$
$e^{i\varphi} = \cos{\varphi} + i \cdot \sin{\varphi}$ - формула Эйлера при $\varphi = \pi$ : $1 + e^{i\pi} = 0$
Формула Муавра
$z^n = (a+ib)^n = |z|^n(\cos{n\varphi} + i\sin{n\varphi})$
$z_1 \cdot z_2 = r \cdot \rho (\cos(\varphi + \alpha) + \sin(\varphi + \alpha))$

Потенциальная форма:
$z^n = r^n e^{in\varphi}$

$\frac{z_1}{z_2} = \frac{z_1 \cdot \bar{z_2}}{|z_2|}$
